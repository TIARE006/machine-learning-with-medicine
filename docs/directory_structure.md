# machine learning with medicine

## Directory structure

- `config/` configuration files
- `data/raw/` raw input datasets
- `data/reference/` reference databases / annotation tables
- `data/docs/` project notes and dataset notes
- `src/` reusable Python modules
- `scripts/pipeline/` main runnable pipelines
- `scripts/analysis/` downstream analysis scripts
- `scripts/plotting/` plotting entrypoints
- `R/differential_expression/` DESeq2 and DEG table scripts
- `R/pathway/` pathway and module scoring scripts
- `R/figures/` figure generation scripts
- `results/clustering/` run-specific clustering outputs
- `results/integrated/` integrated result tables
- `results/figures/` exported final figures
- `results/tables/` exported final tables
